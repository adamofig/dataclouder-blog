# ☁️ Dataclouder Engineering Blog

Este es el blog oficial y repositorio de artículos técnicos de **Dataclouder**, enfocado en arquitecturas cloud, orquestación de agentes inteligentes de IA, ingeniería de software moderna y metodologías de desarrollo acelerado.

---

## 🚀 Base del Proyecto

Este blog está construido sobre la plataforma **Astro v5**, **Tailwind CSS** y estilizado bajo el **Sistema de Diseño Oficial de Dataclouder** (Deep Purple `#2d0c62` & Neon Mint `#4EF9BA`, Glassmorphism con desenfoque de 10px y fondos animados flotantes de 40s).

### Características Principales:
*   **Identidad Visual Dataclouder**: Paleta cromática semántica adaptativa (Deep Purple en Light Mode / Neon Mint en Dark Mode).
*   **Glassmorphism & Micro-interacciones**: Tarjetas translúcidas con desenfoque (`backdrop-filter`) y resplandores neón interactivos.
*   **Fondos Vectoriales Animados**: Patrones SVG orgánicos y flotantes (`body::before`).
*   **Transiciones Fluidas**: Navegación instantánea mediante Swup.
*   **Búsqueda Instantánea**: Búsqueda estática offline con Pagefind.
*   **Bloques de Código Enriquecidos**: Resaltado de sintaxis con Expressive Code y botón de copiado de Markdown completo.

---

## ⚡ Comandos y Desarrollo Local

Todos los comandos se ejecutan desde el directorio `dataclouder-blog`:

| Comando | Acción |
| :--- | :--- |
| `pnpm install` | Instala todas las dependencias del proyecto. |
| `pnpm run dev` | Inicia el servidor de desarrollo en `http://localhost:4321`. |
| `pnpm run build` | Compila el sitio estático final en `./dist/` e indexa el contenido con Pagefind. |
| `pnpm run preview` | Previsualiza localmente el build estático de producción. |
| `pnpm run format` | Da formato y linter al código mediante Biome. |
